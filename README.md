# IP Blocklist

Автоматически обновляемый список IP-адресов для блокировки и фильтрации трафика.

## Назначение
Генерация и поддержание актуальной базы нежелательных IP (сканеры, боты, вредоносные узлы) с помощью GitHub Actions для использования в фаерволах и средствах защиты.

## Структура
- `.github/workflows/` — Автоматический сбор и компиляция списков по расписанию.
- Сгенерированные файлы готовы к прямому скачиванию и использованию в сетевых фильтрах.
